# TUSG AI ナビゲーター『エミリー』アセット

## キャラクター設定

- **名前**: エミリー (Emily)
- **肩書**: TUSG AI ナビゲーター
- **性質**: **AI で生成された架空のキャラクター** (実在人物ではない)
- **役割**: TUSG の SaaS 販売代理・IT 支援・MEO/AIO サービスの
  情報発信をリールで行うプレゼンター

## 開示ポリシー (重要、AML/透明性ルール準拠)

エミリーは実在人物ではない。以下を必ず遵守:

1. **Instagram bio に明記**: 「TUSG AI ナビゲーター『エミリー』が発信中」
2. **各リール投稿キャプションに明記**:
   「※本投稿の映像は AI ナビゲーター『エミリー』(AI 生成キャラクター) が案内しています」
3. **Meta の AI コンテンツラベル** を必ず有効化
   (Instagram 投稿画面 → 詳細設定 → AI で作成されたコンテンツ を ON)
4. **紹介ページ** (将来): tusg.site/emily 等で「AI ナビゲーターです」と明記した紹介
5. **エミリーが「TUSG に在籍」「担当者」の印象を与える発言は禁止**
   (「弊社の坂本が...」等の第三者言及は OK、「私が担当します」等は NG)

## アセットファイル

- `portrait-01.png` — 元画像 (1145×1374, PNG, 1.8MB)
- `portrait-01.jpg` — Web 用最適化 (1080×1296, JPG 92%, 200KB)
  - リール生成 (D-ID API 送信) と HP 掲載に使用

## 使い分け

- **リール生成**: `portrait-01.jpg` を R2 の `emily/portrait-01.jpg` にアップし、
  D-ID API に渡す
- **HP 掲載**: 同じファイルを紹介ページで使用

## 生成元

AI 画像生成 (詳細は 2026-09-10 時点で坂本さんから提供)。
再生成時のプロンプトメモを追記する場合はこの README に追記のこと。

## リプレース時の注意

将来キャラクター画像を差し替える場合:
1. 新画像を `portrait-02.png` 等の連番で追加 (前バージョンは残す)
2. R2 の `emily/portrait-01.jpg` を新画像で上書き
3. 過去投稿との一貫性が変わるので、Bio で「エミリー v2」等の説明を検討

## ライセンス / 法的注意

- AI 生成画像は「著作権」の解釈が国・プラットフォームで異なる。
  Meta / Instagram では現状 AI 生成物の商用利用は許可されているが、
  「実在の人物を模した肖像」の疑いがある場合はリスクあり。
- エミリーが実在の日本人と偶然そっくりだった場合の対応: 該当人物から
  申立があれば即使用停止し、別画像に差し替える。
