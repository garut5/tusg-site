ストアコネクト プライバシーポリシー

Google ビジネスプロフィール連携基盤「ストアコネクト」における情報の取扱いについて定めます。

最終改定日：2026年8月5日

1. 本ポリシーの対象

本ポリシーは、株式会社camomile および合同会社TUSG（以下あわせて「当社ら」といいます）が提供する以下のサービスにおいて、Google ビジネスプロフィール（以下「GBP」）と連携する機能（以下「本連携機能」といいます）に適用されます。

サービス名提供者
LOCOREACH株式会社camomile
lococreate株式会社camomile
meoreport（社内利用）株式会社camomile
FanMap合同会社TUSG

本連携機能は、当社らが共同で運用する単一の Google Cloud プロジェクトおよび OAuth アプリケーション「ストアコネクト」を通じて提供されます。

Google の認証画面には「ストアコネクト」と表示されます

ご契約中のサービス名とは異なる名称が表示されますが、正常な動作です。

3. 取得する情報

本連携機能では、お客様が Google アカウントで明示的に許可された場合に限り、https://www.googleapis.com/auth/business.manage の権限により以下の情報を取得します。

  • お客様が管理権限をお持ちのビジネスプロフィールのアカウント情報および店舗一覧
  • 店舗の基本情報（名称、住所、電話番号、営業時間、カテゴリ 等）
  • パフォーマンス指標（表示回数、通話クリック数、ルート検索数、ウェブサイトクリック数、メニュークリック数、検索キーワード）
  • 口コミの内容、評価、投稿者の公開情報、および返信
  • 投稿（最新情報）の内容

取得の対象は、お客様ご自身が管理権限をお持ちのビジネスプロフィールに限られます。第三者のビジネスプロフィールを取得することはありません。

本連携機能が要求する権限は上記1つのみです。Gmail、Google ドライブ、連絡先など、他の Google サービスには一切アクセスしません。

4. 利用目的

取得した情報は、次の目的にのみ利用します。

  • お客様のビジネスプロフィールの運用代行および運用支援
  • お客様への効果測定レポートの作成および提供
  • お客様が承認された内容での口コミ返信および投稿の実施
  • サービスの不具合対応および品質改善

5. 第三者提供および二次利用の禁止

  • 取得した情報を、当該情報が帰属するお客様以外の第三者へ提供することはありません。
  • 販売、再販、譲渡、一般公開を一切行いません。
  • 広告配信の対象選定や、他のお客様向けの分析には使用しません。
  • AI・機械学習モデルの学習データとして使用しません。

ただし、法令にもとづく開示請求があった場合など、法律上必要な場合はこの限りではありません。

6. Google API Services User Data Policy への適合

本連携機能による Google ユーザーデータの取得・利用・保存・共有は、Google API Services User Data Policy（Limited Use requirements を含む）に準拠します。

7. 口コミの取扱いに関する方針

  • 星評価の高さを条件として口コミ投稿を促すこと（レビューゲーティング）は行いません。
  • 口コミの投稿に対して、金銭・割引・景品等の対価を提供することはありません。
  • AI による返信文の生成を行う場合、お客様または当社らの担当者の確認・承認を経ずに投稿することはありません。
  • 低評価（星1・星2）の口コミへの返信は、必ずお客様の確認を経て投稿します。

8. 保存期間および削除

  • 取得した情報は、ご契約期間中および契約終了後1年間保存します。
  • お客様はいつでも連携を解除できます。解除された時点で、暗号化して保存しているアクセストークンおよびリフレッシュトークンを直ちに削除します。
  • 保存データの削除をご希望の場合は、下記の窓口までご連絡ください。ご本人確認のうえ、10営業日以内に削除します。
  • Google アカウント側からの連携解除は サードパーティ アプリとサービス からいつでも行えます。

9. 安全管理措置

  • 通信はすべて TLS により暗号化します。
  • アクセストークンおよびリフレッシュトークンは AES-GCM により暗号化して保存します。
  • データベースへのアクセスは、業務上必要な担当者に限定します。
  • 暗号鍵はアプリケーションのソースコードとは分離して管理します。
